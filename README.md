
# Subway 웹사이트 UI 구현


### 📈 프로젝트 소개
> Subway 공식 웹사이트를 참고하여 제작한 클론 코딩 프로젝트입니다.
HTML, CSS, JavaScript를 활용하여 퍼블리셔 관점에서 마크업의 구조를 설계하고
사용자 경험을 위한 디테일한 UI 동작을 구현하는 데 집중하여 작업했습니다.  
🔗 **Repository** : https://github.com/ah314-git/subway-clone  
🔗 **Live Demo** : https://ah314-git.github.io/subway-clone/


### 📈사용 기술

* Language: HTML5, CSS3, JavaScript (ES6+)
* Library: jQuery, Slick.js
* Deployment: GitHub Pages





### 📈페이지 구성

* 메인 페이지 | index.html | 메인 배너 영역, 주요 메뉴 소개, 공통 헤더/푸터
* 메뉴 목록 | menu.html | 카테고리별 탭 필터링, 메뉴 리스트, hover 인터랙션



### 📈핵심 구현 포인트

**1. 데이터 속성을 활용한 메뉴 필터링 로직**  
단순히 요소를 숨기고 보여주는 것이 아닌 한 메뉴가 여러 카테고리에 속할 수 있도록
확장성을 고려하여 data-category를 설계했습니다.
→ 문자열 분리 방식(split)을 도입하여 메뉴 데이터가 늘어나거나 복합적인 카테고리가
추가되어도 코드 수정 없이 유연하게 대응할 수 있도록 구현했습니다

**2. 스크롤 기반 Sticky Header 인터랙션 구현**  
스크롤 위치에 따라 헤더가 자연스럽게 고정되도록 구현하고,
고정 상태에서는 높이와 스타일을 함께 변경하여 화면을 더 넓게 활용할 수 있도록 구성했습니다.
단순 고정이 아닌 상태 변화가 느껴지도록 전환 효과를 적용해
사용자 경험을 해치지 않도록 신경 썼습니다.

**3. 카드 인터랙션의 단계적 애니메이션 처리**  
메뉴 카드에 마우스를 올렸을 때 시각적인 피드백이 단계적으로 나타나도록
CSS transition과 transform을 조합해 인터랙션을 구현했습니다.
요소의 등장 순서와 이동 거리를 조절하여 과하지 않으면서도
사용자의 시선을 자연스럽게 유도하는 효과를 목표로 했습니다.




### 💡향후계획

**서브 페이지 확장**: 현재는 메인 페이지와 메뉴 페이지를 구현한 상태이며
브랜드 소개, 매장 찾기, 이벤트 등 다양한 서브 페이지를 추가하여
사이트의 전체적인 완성도를 높일 예정입니다.

**UI/UX 개선**: 각 페이지 성격에 맞는 레이아웃을 연구하고
퍼블리싱 완성도를 높여 실제 서비스와 유사한 사용자 경험을 제공하고자 합니다.
